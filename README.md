# NoteDesk

一款 Windows 桌面便签：让想法停靠，让小事完成。

## 运行

从 Release 下载 `NoteDesk.exe` 后双击即可运行；完整包解压后的 EXE 位于根目录，从源码构建后的 EXE 默认位于 `dist/NoteDesk.exe`。无需安装 Node.js、Python 或开发工具；使用 Windows 自带的 .NET Framework 4.x 桌面运行环境（开发与验证环境为 Windows 11 / .NET Framework 4.8.1）。

第一次打开是空白便签列表，点击「新建便签」。拖动便签顶部 NOTEDESK 区域移动，拖动右下角调整大小。标题和正文直接编辑并自动保存。在「添加待办」下输入内容后按 Enter 或点击 ＋。待办右侧 ··· 可编辑文字、设置截止日期和提前提醒。

## 便签与完成

- 每张便签可独立置顶、隐藏、换色及调整背景透明度；只改变背景透明度，文字保持清晰。首版提供半透明渐变背景，不保证操作系统原生磨砂模糊效果。
- 普通文字与待办混排，只有包含待办的便签才显示进度条。
- 点击待办圆圈后，对勾绘制、按钮回弹、粒子和进度条动画提供反馈；已完成内容收进可展开区域。
- 勾选最后一条待办后停留约 3 秒，自动归档；弹出 8 秒的撤销入口。管理窗口也能撤销最近一次操作。
- 纯文字便签可从 ··· 菜单点击「完成并归档」。
- 便签上的 × 和管理窗口的关闭按钮只隐藏窗口。系统托盘提供新建、管理和退出入口。

## 提醒

支持一次性提醒、自定义提前分钟数，以及 10 / 30 / 60 分钟稍后提醒。后台便签也可以弹出提醒卡片。多个到期事项在一次提醒窗口中汇总；不会抢走键盘焦点。已完成或归档的事项不再生成新提醒。关闭提醒卡片代表本次提醒已阅，不会反复弹出。

软件必须运行才会提醒。关机、休眠或退出期间错过的提醒，在重新启动或唤醒后检查。可在设置里开启「登录 Windows 后自动启动」，默认关闭。程序移动位置后，请重新关闭再开启此选项以更新路径。

## 留下记录

管理窗口可搜索标题、正文和待办，查看桌面显示/后台状态，浏览时光归档与回收站。归档可恢复到桌面；保留原来的完成状态和内容，不会因已全部完成而再次自动归档，旧提醒不会再次弹出。需要继续提醒时可编辑待办重新设置时间。

编辑停止约 1.1 秒后保留内容版本；完成、删除等操作也记录版本。恢复旧版本会保留当前版本，便于反悔。首版未限制历史条数，可定期导出备份。

## 数据与备份

数据默认保存在 `%LOCALAPPDATA%\NoteDesk\notes.json`，上一次保存的副本为 `notes.json.bak`。保存采用临时文件加原子替换；主数据损坏时尝试恢复备份。无法读取两份数据时停止启动并保留文件，避免覆盖。

在设置页导出/导入完整 JSON 备份，包含正文、待办、窗口状态和历史版本。导入以编号合并，相同编号跳过，不覆盖现有内容；导入便签默认隐藏。数据未加密，也不上传云端。

## 构建与验证

代码在 `src/NoteDesk.cs`，使用 C# / WPF 与系统托盘，无第三方运行依赖。可使用 .NET Framework 自带编译器构建：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

测试只在独立临时目录运行，请勿指定真实数据目录：

```powershell
$qa = Join-Path $env:TEMP ('NoteDesk-test-' + [Guid]::NewGuid().ToString('N'))
Start-Process .\dist\NoteDesk.exe -ArgumentList @('--self-test', '--data-root', $qa) -Wait
Get-Content (Join-Path $qa 'test-results.txt')
Start-Process .\dist\NoteDesk.exe -ArgumentList @('--integration-test', '--data-root', ($qa + '-ui')) -Wait
Get-Content (Join-Path ($qa + '-ui') 'integration-results.txt')
```

`--preview --data-root <测试目录>` 会渲染界面 PNG 后退出。模型测试覆盖持久化、历史恢复、备份、提前提醒、提醒去重和稍后提醒；桌面集成测试覆盖真实 WPF 窗口构造、显示/隐藏、计时归档、撤销、回收站和归档恢复。

## 首版边界

当前为便携版，无安装器与自动更新，未进行代码签名。无云同步、富文本、重复提醒或永久删除入口。不同 Windows 缩放比例、多个显示器、长时间休眠和系统托盘折叠状态仍需实际使用验证。
