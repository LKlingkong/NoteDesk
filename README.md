# NoteDesk

当前源码版本：**v1.1.0** · [已发布版本](https://github.com/LKlingkong/NoteDesk/releases) · [更新日志](RELEASE_NOTES.md)

一款 Windows 桌面便签：让想法停靠，让小事完成。

## 运行

从 Release 下载 `NoteDesk.exe` 后双击即可运行；完整包解压后的 EXE 位于根目录，从源码构建后的 EXE 默认位于 `dist/NoteDesk.exe`。无需安装 Node.js、Python 或开发工具；使用 Windows 自带的 .NET Framework 4.x 桌面运行环境（开发与验证环境为 Windows 11 / .NET Framework 4.8.1）。

第一次打开是空白便签列表，点击「新建便签」。拖动便签顶部 NOTEDESK 区域移动，拖动右下角调整大小。标题和正文直接编辑并自动保存。在「添加待办」下输入内容后按 Enter 或点击 ＋。待办右侧 ··· 可编辑文字、设置截止日期和提前提醒。

## 外观与全局快捷键（v1.1.0）

界面统一为 macOS 风格的磨砂背景、蓝色强调色、圆角与细边框；保留 Windows 窗口按钮的位置与操作方式。「设置与备份 → 外观」提供跟随系统、浅色和深色，切换后立即生效，保留正在编辑的正文和光标位置。五种便签颜色会随主题适配。

程序运行时，在任何软件中按 **Ctrl + Alt + N**，即可新建独立空白便签并直接输入正文，不必先打开管理窗口。便签出现在鼠标所在屏幕的工作区中央，连续新建稍微错开。长按不会连续创建；新建时激活窗口，之后按普通窗口层级显示，可单独置顶。

「设置与备份 → 快捷新建」可修改或关闭快捷键；点击「更改」后按下组合键，Esc 取消。需要 Ctrl、Alt 或 Win 参与组合，F12 为系统保留键。被其他程序占用时明确提示，已有快捷键保持不变。录制时暂停新建，结束或取消后恢复。

关闭管理窗口后，程序留在托盘，快捷键和提醒继续工作；从托盘退出后失效。登录自动启动仍由设置页单独控制。若启动时快捷键被占用，主窗口状态栏会提示，可到设置页换键。软件尚未运行时，快捷键不能启动程序。

升级前从托盘退出旧版，再运行新版。已有便签、待办、提醒、历史、窗口位置及备份继续使用，无需迁移。

## 便签与完成

- 每张便签可独立置顶、隐藏、换色及调整背景透明度；只改变背景透明度，文字保持清晰。在支持的 Windows 11 上使用原生 Acrylic 磨砂背景；系统关闭透明效果、开启高对比度或原生效果不可用时使用清晰的实色背景。
- 普通文字与待办混排，只有包含待办的便签才显示进度条。
- 点击待办圆圈后，以简短勾选、淡出和进度反馈确认完成；已完成内容收进可展开区域。键盘操作即时响应，并尊重 Windows 关闭动画的设置。
- 勾选最后一条待办后停留约 3 秒，自动归档；弹出 8 秒的撤销入口。管理窗口也能撤销最近一次操作。
- 纯文字便签可从 ··· 菜单点击「完成并归档」。
- 便签上的 × 和管理窗口的关闭按钮只隐藏窗口。系统托盘提供新建、管理和退出入口。

## 提醒

支持一次性提醒、自定义提前分钟数，以及 10 / 30 / 60 分钟稍后提醒。后台便签也可以弹出提醒卡片。多个到期事项在一次提醒窗口中汇总；不会抢走键盘焦点。已完成或归档的事项不再生成新提醒。关闭提醒卡片代表本次提醒已阅，不会反复弹出。

软件必须运行才会提醒。关机、休眠或退出期间错过的提醒，在重新启动或唤醒后检查。可在设置里开启「登录 Windows 后自动启动」，默认关闭。程序移动位置后，请重新关闭再开启此选项以更新路径。

## 留下记录

管理窗口可搜索标题、正文和待办，查看桌面显示/后台状态，浏览时光归档与回收站。归档可恢复到桌面；保留原来的完成状态和内容，不会因已全部完成而再次自动归档，旧提醒不会再次弹出。需要继续提醒时可编辑待办重新设置时间。

编辑停止约 1.1 秒后保留内容版本；完成、删除等操作也记录版本。恢复旧版本会保留当前版本，便于反悔。首版未限制历史条数，可定期导出备份。

## 数据与备份

数据默认保存在 `%LOCALAPPDATA%\NoteDesk\notes.json`，上一次保存的副本为 `notes.json.bak`。保存采用临时文件加原子替换；主数据损坏时尝试恢复备份。无法读取两份数据时停止启动并保留文件，避免覆盖。

在设置页导出/导入完整 JSON 备份，包含正文、待办、窗口状态和历史版本。导入以编号合并，相同编号跳过，不覆盖现有内容；导入便签默认隐藏。数据未加密，也不上传云端。

## 构建与验证

代码在 `src/NoteDesk.cs`，使用 C# / WPF 与系统托盘，无第三方运行依赖。可使用 .NET Framework 自带编译器构建：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

测试只在独立临时目录运行，请勿指定真实数据目录：

```powershell
$qa = Join-Path $env:TEMP ('NoteDesk-test-' + [Guid]::NewGuid().ToString('N'))
Start-Process .\dist\NoteDesk.exe -ArgumentList @('--self-test', '--data-root', $qa) -Wait
Get-Content (Join-Path $qa 'test-results.txt')
Start-Process .\dist\NoteDesk.exe -ArgumentList @('--integration-test', '--data-root', ($qa + '-ui')) -Wait
Get-Content (Join-Path ($qa + '-ui') 'integration-results.txt')
```

`--preview --data-root <测试目录>` 会渲染界面 PNG 后退出。模型测试覆盖持久化、历史恢复、备份、提前提醒、提醒去重和稍后提醒；桌面集成测试覆盖真实 WPF 窗口构造、显示/隐藏、计时归档、撤销、回收站和归档恢复。

## 首版边界

当前为便携版，无安装器与自动更新，未进行代码签名。无云同步、富文本、重复提醒或永久删除入口。不同 Windows 缩放比例、多个显示器、长时间休眠和系统托盘折叠状态仍需实际使用验证。

## 界面与动画更新（2026-11-04）

采用暖白底色、鼠尾草绿强调色与五种低饱和便签色，统一按钮、圆角输入框、菜单、细滚动条、进度条与窗口字体。管理中心增加导航选中状态和状态标签，键盘焦点清晰可见。便签添加待办区域固定在底部，不会被长内容挤出；输入框随窗口宽度伸缩，添加后可连续输入。

鼠标按压反馈为 100–120ms，待办完成淡出与进度反馈为 180ms，辅助窗口淡入为 200ms。移除弹跳和粒子；键盘操作及 Windows 关闭动画时即时更新。列表刷新不播放入场动画。

新增 `--render-preview --data-root <独立测试目录>`，在不显示窗口的情况下生成各页面截图；`--integration-test --headless --data-root <独立测试目录>` 运行离屏集成验证。测试目录必须与真实数据目录隔离；截图命令会生成样例便签。

第二轮边界修整：便签最小尺寸为 300×380，管理窗口为 820×540；侧栏可滚动，操作按钮可换行，状态栏为撤销按钮预留空间。长卡片标题最多两行，悬停可查看完整标题；正文摘要最多两行。键盘完成一项后焦点移到下一项，没有剩余待办时移到添加输入框。图标按钮补充读屏名称。

升级时先从托盘退出旧版，再运行新版。默认数据位置不变，无需迁移便签。

## 升级验证

运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\verify.ps1`：构建后依次验证兼容旧数据、原生快捷键冲突/换键/停用/释放、真实按键创建与正文焦点、长按去重、快捷键录制、主题切换保留输入和光标、小工作区窗口边界、无透明效果回退，再运行已有模型与集成测试并生成浅色/深色全页面截图。测试数据在 `.qa` 和独立临时目录，验证记录在 `dist/validation.txt`。原生全局按键测试需要普通交互式 Windows 桌面环境。

`--render-preview --appearance light|dark --data-root <独立测试目录>` 可分别生成两套主题截图。物理多显示器混合 DPI、高对比度各系统配色及长时间休眠尚未全面实测。
