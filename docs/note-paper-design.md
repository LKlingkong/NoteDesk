# 透明纸笺设计（已确认，本地工作版本）

用户确认：轻盈透明纸笺；常驻精简工具栏和外观面板；统一圆形勾选、轻量分隔线、固定底部输入区与克制完成反馈。

| Before | After | Why |
| --- | --- | --- |
| 顶部文字按钮和字符图标 | 28px 常驻矢量置顶、更多、隐藏控件 | 图标形态和命中区域一致 |
| 循环切换颜色 | 五色直接选择，选中色描边与对勾 | 状态明确，减少来回点击 |
| 卡片化待办和字体圆圈 | 矢量圆形勾选、透明行与细分隔线 | 阅读层级更轻 |
| 无明确的编辑保存状态 | 编辑后提示稍后保存，成功后提示已保存 | 不把编辑中误报为已保存 |
| 置顶操作重建编辑区 | 原地修改窗口置顶和控件状态 | 保留正文选区和光标 |

纸笺圆角为 16px，背景保持低饱和渐变，直接透出真实桌面。阴影单独绘制并裁掉纸笺内部，不参与背景 Alpha，避免回归透明度遮挡问题。高对比度下禁用阴影、使用实色纸面和系统色描边。

颜色与背景不透明度集中于更多面板，调节即时预览并在面板关闭时保存。背景不透明度为 25%–100%，前景始终清晰。面板留在打开状态以便连续调整。

待办鼠标勾选后划线并在 180ms 内淡出到折叠区，进度反馈为 180ms；键盘完成立即更新。新建、输入、滚动、拖动不添加入场或跟随动画。纯文字便签隐藏待办标题与进度条。
