# NoteDesk v1.2.2

本次更新修复便签背景透明度失效，并完成透明纸笺界面与交互优化。

## 重要修复
- 修复背景 Alpha 被窗口底色与原生 Acrylic 遮挡的问题。便签使用逐像素透明，背景不透明度支持 25%–100%，正文和按钮保持清晰。
- 透明度面板显示实时百分比，支持方向键调节、连续调整和关闭即保存；高对比度下保持实色并明确提示。
- 新增隐藏原生窗口分层标志、合成底层和浅深色最终像素回归，避免仅验证画刷数值而漏掉真实透明链路。

## 便签设计
- 16px 圆角、低饱和渐变、细描边和柔和外部阴影；阴影不叠入纸面，不干扰透明度。
- 常驻矢量置顶、更多和隐藏工具栏；五种颜色直接选择，显示当前选中色。
- 待办采用圆形矢量勾选和轻量分隔线，底部固定添加区域，纯文本便签隐藏任务进度。
- 置顶、换色保留正文和选区；编辑时显示待保存状态，保存成功后更新提示。

## 交互与动画
- 鼠标勾选后划线并在 180ms 内淡出，键盘完成即时响应；按钮支持按压中断复位，菜单锚定实际触发按钮。
- 搜索支持 Ctrl+F、Esc 清空和清空按钮，连续输入合并处理；分类记住滚动位置，切换主题保留设置控件。
- 提醒表单支持 Enter 保存、Esc 取消，未启用提醒时禁用时间选项。
- 复用玻璃材质对象，减少实时调节时的重复分配。

## 验证与升级
原生透明度、便签交互、外观、快捷键注册生命周期、壁纸像素、模型与归档恢复集成、浅深色紧凑长文本验证通过。未向真实桌面注入按键；物理多屏混合 DPI 和长期休眠仍未全面验证。

先从系统托盘退出旧版，再运行新版。数据仍位于 %LOCALAPPDATA%\NoteDesk，无需迁移。便签使用可控透明而非原生桌面磨砂；管理窗口保留壁纸玻璃。自定义壁纸文件仍需单独备份。
