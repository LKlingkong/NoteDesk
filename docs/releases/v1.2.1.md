## 壁纸玻璃界面与全局快捷键

这是 v1.0.1 之后的公开升级，包含此前本地完成的界面与快捷键改造。

- 管理、设置及标题栏采用「内置云朵壁纸 + 分离毛玻璃浮层」，支持浅色、深色和跟随系统。
- 新默认值：**模糊 25 px、不透明度 60%、壁纸明暗 80%**。支持换壁纸、实时调节、位置微调与恢复默认。
- **Ctrl + Alt + N** 在其他软件中也能新建桌面便签并直接输入，支持改键、停用、冲突提示及长按去重。
- 改善窗口拖动、缩放、最大化与关闭驻留，修正任务栏遮挡、壁纸首次显示、局部模糊和滚动对齐。
- 自定义壁纸复制到本机数据目录；损坏或缺失时回退默认图，重新选择可恢复。保留原有便签、待办、提醒、历史、归档与备份功能。
- 整理项目目录，新增可重复打包脚本，并通过模型、窗口集成、实际按键、壁纸像素和浅深色界面检查。

## 下载

- **NoteDesk.exe**：直接运行的 Windows 便携版，默认壁纸已嵌入程序。
- **NoteDesk-Windows-v1.2.1.zip**：EXE、源码、资源、脚本、说明、预览与验证记录。
- **SHA256SUMS.txt**：EXE 与完整包的 SHA-256 校验值。

## 升级

先从系统托盘退出旧版，再运行新版。便签数据继续保存在 `%LOCALAPPDATA%\NoteDesk`，无需迁移。

**已有自定义参数会保留。** 要采用新的 25 px / 60% / 80%，请在「设置与备份 → 壁纸与玻璃」点击「恢复默认」。首次运行和缺少外观设置的旧数据会自动采用新默认值。

JSON 备份不包含自定义图片，换电脑时请复制数据目录中的 `wallpapers` 文件夹，或重新选择壁纸。程序运行时快捷键与提醒才会生效；原生桌面磨砂受 Windows 与透明设置影响。物理混合 DPI 多屏、高对比度各配色和长时间休眠尚未全面实测。
