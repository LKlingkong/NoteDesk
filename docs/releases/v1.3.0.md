# NoteDesk v1.3.0

桌宠现在可以接手便签提醒，也会在你勾完一张便签时庆祝。

- 在「设置与备份 → 桌宠」导入 Codex v2 桌宠包或静态 PNG，也可以从包含兼容资源的公开 GitHub 仓库导入。小蕾米是默认桌宠选项，通过上游仓库导入。
- 当前桌宠可用时优先显示提醒气泡，可打开便签、选择 10／30／60 分钟后提醒，或收起本次提示。多个提醒依次显示，桌宠不可用时回到原提醒窗口。
- 勾完一张便签的最后一项时，当前桌宠播放庆祝动作。右键桌宠可新建便签或打开管理中心。
- 首次导入后显示桌宠，支持拖动记位、可选置顶和托盘显隐。可开启沿当前显示器底边走动，拖动或显示气泡时暂停。
- 托盘可临时开启桌宠鼠标穿透。桌宠本体允许点击通过，提醒气泡仍能操作。
- 提供大肥鱼默认造型的本地转换工具，包含待机、走动、提醒和庆祝。转换后的透明 PNG 图集可通过原有桌宠入口导入。
- 改进透明 WebP 解码，保留图集的透明像素。
- 便签拖到屏幕工作区或可见窗口边缘时自动对齐。按住 Alt 可以临时跳过吸附。

桌宠资源保存在 NoteDesk 数据目录的 `pets` 子目录。动态桌宠使用 1536 × 2288 的 Codex v2 图集，WebP 解码取决于 Windows 的图像支持。小蕾米由 HanaAyane 提供。[上游仓库](https://github.com/HanaAyane/remielle-codex-pet) · [素材使用说明](https://github.com/HanaAyane/remielle-codex-pet/blob/main/ASSET-USAGE.md)

大肥鱼的贴图从用户本地 Coopanion 源码生成。发布包提供转换工具与 [导入步骤](https://github.com/LKlingkong/NoteDesk#桌宠与便签磁吸)。[Coopanion 素材声明](https://github.com/Pal-AI-Lab/Coopanion/blob/main/packages/cortico-world-desktop-pet/THIRD_PARTY_NOTICES.md)

## 升级与试用

先从托盘退出旧版，再运行新版 `NoteDesk.exe`。

1. 导入小蕾米，再导入一张 PNG 或另一个兼容仓库。检查切换、拖动、置顶、托盘隐藏和重启后的恢复。
2. 勾完一张便签的待办，查看庆祝动作。触发提醒，试用打开便签和稍后提醒。
3. 把便签拖近屏幕边缘和普通窗口，检查吸附、拉开和按住 Alt 拖动。使用多屏时，检查不同缩放比例下的对齐。
