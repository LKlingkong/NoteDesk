# 交互与动画优化（基于 v1.2.1，尚未发布）

保留现有壁纸、玻璃材质和浅深色主题，优先修整高频操作反馈。

| Before | After | Why |
| --- | --- | --- |
| 悬停瞬间切换、按压中断可能停留在缩放态 | 100ms 悬停、100/120ms 按下/释放；捕获中断和禁用时复位 | 连续操作可以自然中断 |
| 使用通用 CubicEase | 统一使用 (0.23, 1, 0.32, 1) 响应曲线 | 快速给出初始反馈且无过冲 |
| 菜单依赖键盘焦点定位 | 锚定实际触发按钮，鼠标打开时以 140ms 从锚点展开 | 菜单位置与操作来源一致 |
| 每输入一个字符重建搜索结果 | 120ms 合并连续输入；Ctrl+F、Esc 和清空按钮 | 减少重绘，支持键盘连续操作 |
| 重新点击当前分类或切主题重建控件 | 当前分类不重建，保存分类滚动位置，保留设置控件 | 避免焦点和滚动位置跳动 |
| 每次玻璃更新创建材质对象 | 复用色刷与阴影，主题变化时才重建边缘渐变 | 减少实时调整时的分配 |
| 提醒表单缺少明确的键盘动作 | Enter 保存、Esc 取消；未启用提醒时禁用时间设置 | 表单状态清晰，操作更直接 |

键盘操作即时更新，尊重系统关闭动画的设置；搜索、列表刷新和全局快捷新建不添加入场动画。只动画化缩放与透明度，不对布局、壁纸模糊半径增加动画。

## 验证

新增 tests/InteractionTests.cs 并接入 tests/run.ps1。覆盖连续输入只显示最新结果、Esc 清空、查找命令、主题控件保留、当前分类不重建、鼠标捕获中断与禁用复位、提醒表单状态及默认/取消按钮。原有外观、壁纸像素和窗口集成测试保持通过。

在普通 Windows 开发环境可运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/verify.ps1 -BuildDirectory dist/interaction-polish -SkipDesktop
```

SkipDesktop 跳过向真实桌面注入按键的测试，保留原生快捷键注册生命周期验证。本轮未操作真实用户数据，未推送代码或发布 Release。
